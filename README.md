## 🌟 Возможности

Программа обладает огромным набором функций для точечной настройки системы под любые игровые задачи:

- 🖥️ **Автоматическое обнаружение оборудования** (CPU, GPU, RAM, VRAM)
- 📊 **3 продвинутых способа определения FPS**:
  - **Машинная калибровка** — математическая аппроксимация FPS для разных пресетов графики на базе всего одного вашего ручного замера.
  - **AI-калибровка (Gemini)** — использование искусственного интеллекта для точного прогнозирования производительности в любых условиях.
  - **Локальная калибровка** — оценка FPS на основе системных требований игры без необходимости её запуска.
- 🤖 **Интеграция с ИИ (AI Scout)**:
  - Поддержка нескольких провайдеров, таких как **Gemini, OpenRouter и GroqCloud**.
  - ИИ-ассистент анализирует ваше оборудование и подсказывает, какие конкретно параметры графики нужно изменить, чтобы получить стабильную частоту кадров (например, 165 FPS для высокогерцовых мониторов).
- 🌩️ **Облачная синхронизация (Яндекс.Диск)**:
  - Резервное копирование и восстановление пресетов и профилей калибровки. Ваши настройки всегда с вами!
- 🔧 **Менеджер пользовательских профилей** с возможностью хранения истории всех замеров.

## 🚀 Установка

### С помощью готового .exe файла (рекомендуется)

1. Скачайте готовый `FPS_Targeter.exe` из папки `src/dist/`.
2. Убедитесь, что в папке `src/dist/` также находятся файлы конфигурации:
   - `game_requirements.json`
   - `hardware_benchmark.json`
   - `overlay_settings.json`
3. Запустите его без установки. Дополнительная информация доступна в `START.md` (находится в корне проекта).

### С помощью исходного кода

1. Убедитесь, что у вас установлен Python 3.8 или выше.
2. Скачайте исходный код.
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   cd src
   python main.py
   ```

## 🎮 Быстрый старт

1. Запустите `FPS_Targeter.exe` (из `src/dist/`) или `python main.py` (из `src/`).
2. Программа автоматически обнаружит ваше оборудование.
3. Создайте или выберите профиль в меню.
4. Выберите игру и проведите калибровку (оценку) ожидаемого FPS удобным вам способом.
5. При необходимости воспользуйтесь вкладкой AI Scout для получения советов от ИИ.

## 📋 Использование (Калибровка и ИИ)

В приложении нет внутриигрового оверлея, зато оно предлагает мощный набор инструментов для **предоптимизации**.

**Калибровка**:
Перейдите на вкладку "Калибровка". Введите результаты одного замера производительности (например, на средних настройках). Нажмите **"Машинная калибровка"**, и приложение само рассчитает, сколько FPS вы получите на Ultra или Low настройках. Также вы можете использовать "AI-калибровку" или "Локальную", если вы еще не запускали игру.

**AI Scout**:
На вкладке "AI Scout" вы можете задать целевой FPS. Выберите желаемую нейросеть (Gemini, OpenRouter, GroqCloud), укажите API-ключ, и AI выдаст развернутый ответ: какие ползунки в игре нужно подкрутить, нужно ли использовать апскейлинг (например, Lossless Scaling LSFG), и хватит ли вашей видеокарты для вашей герцовки.

**Облачные сохранения**:
В настройках вы можете привязать OAuth-токен Яндекс.Диска. В один клик сохраняйте всю базу данных калибровок (`fps_data.db`) в облако в формате ZIP и восстанавливайте её на другом ПК.

## 🔧 Сборка в .exe

### Способ 1: Простая сборка (рекомендуется)

```bash
cd src
simple_build.bat
```

### Способ 2: Полная сборка

```bash
cd src
build.bat
```

### Способ 3: Ручная сборка

```bash
cd src
pip install pyinstaller
pyinstaller --onefile --windowed --clean main.py
```

Готовый .exe файл будет находиться в папке `src/dist/`. Скрипты сборки `simple_build.bat`, `build.bat` и `build.sh` автоматически скопируют все необходимые `.json` файлы конфигурации в папку `dist/`. Если вы собираете вручную (Способ 3), вам может потребоваться скопировать их самостоятельно.

**Содержимое папки dist/ после сборки:**
- `FPS_Targeter.exe` (86 MB) - главный исполняемый файл
- `game_requirements.json` (205 байт) - база требований игр
- `hardware_benchmark.json` (4086 байт) - база бенчмарков
- `overlay_settings.json` (150 байт) - настройки (если используются)

## ❓ FAQ / Часто задаваемые вопросы

- **Q: При запуске из исходников возникают проблемы с правами доступа (wmi / pywin32).**
  - **A:** Для корректного сбора информации о системе библиотекам `wmi` и `pywin32` могут потребоваться права администратора. Попробуйте запустить консоль от имени Администратора.
- **Q: Появляются ошибки, связанные с pynvml. Я не использую видеокарту от NVIDIA.**
  - **A:** Библиотека `pynvml` предназначена для работы с видеокартами NVIDIA. Если у вас видеокарта другого производителя (AMD, Intel), в логах могут появляться предупреждения об отсутствии совместимого драйвера. Это нормальное поведение и не мешает работе программы.
- **Q: Что происходит при первом запуске .exe файла?**
  - **A:** При первом запуске в папке `src/dist/` автоматически создадутся служебные файлы: `fps_data.db`, `fps_settings.json`, `fps_targeter.log`, `game_presets_db.json`. Это нормально, данные файлы используются для локального хранения настроек и логов.
