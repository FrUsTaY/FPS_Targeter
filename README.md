## 🚀 Установка

### С помощью .exe файла (рекомендуется)

1. Скачайте готовый `FPS_Targeter.exe` из папки `src/dist/`
2. Убедитесь, что в папке `src/dist/` также находятся:
   - `game_requirements.json`
   - `hardware_benchmark.json`
   - `overlay_settings.json`
3. Запустите его без установки

**Документация:**
- `START.md` - подробное руководство по запуску (находится в корне проекта)

### С помощью исходного кода

1. Убедитесь, что у вас установлен Python 3.8+
2. Скачайте исходный код
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   cd src
   python main.py
   ```

## 🎮 Быстрый старт

1. Запустите `FPS_Targeter.exe` (из `src/dist/`) или `python main.py` (из `src/`)
2. Программа автоматически обнаружит ваше оборудование
3. Создайте или выберите профиль
4. Начните игру — FPS Targeter будет работать в фоне

## 🔧 Сборка в .exe

### Простая сборка (рекомендуется)

```bash
cd src
simple_build.bat
```

### Полная сборка

```bash
cd src
build.bat
```

**Важно**: После сборки файлы .json не копируются автоматически PyInstaller'ом. Выполните ручное копирование:

```powershell
Copy-Item -Path "game_requirements.json", "hardware_benchmark.json", "overlay_settings.json" -Destination "dist\" -Force
```

Готовый .exe файл будет находиться в папке `src/dist/`.

**Содержимое папки dist/ после сборки:**
- `FPS_Targeter.exe` (86 MB) - главный исполняемый файл
- `game_requirements.json` (205 байт) - база требований игр
- `hardware_benchmark.json` (4086 байт) - база бенчмарков
- `overlay_settings.json` (150 байт) - настройки оверлея

## 📋 Использование

### Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Alt+F` | Переключить отображение FPS |
| `Ctrl+Shift+R` | Сбросить настройки |
| `Ctrl+Shift+F` | Переключить FPS |

### Основные функции

- 🖥️ Автоматическое обнаружение оборудования (CPU, GPU, RAM, VRAM)
- 📊 Реальное отображение FPS и нагрузки на систему
- 🎮 Интеллектуальный подбор настроек игр
- 🌩️ Облачная синхронизация настроек между устройствами
- ⚡ Автоматическая оптимизация производительности
- 🔧 Поддержка пользовательских профилей
