# FPS Targeter v2.3

Интеллектуальный трекер FPS и оптимизатор производительности для Windows

## Описание

FPS Targeter — это мощный инструмент для мониторинга и оптимизации производительности игр. Приложение автоматически обнаруживает оборудование, отслеживает FPS в реальном времени и предлагает оптимальные настройки для максимальной производительности.

## Возможности

- 🖥️ Автоматическое обнаружение оборудования (CPU, GPU, RAM, VRAM)
- 📊 Реальное отображение FPS и нагрузки на систему
- 🎮 Интеллектуальный подбор настроек игр
- 🌩️ Облачное синхронизация настроек между устройствами
- ⚡ Автоматическая оптимизация производительности
- 🔧 Поддержка пользовательских профилей

## Системные требования

- Windows 10/11 (64-bit)
- Python 3.8+
- 4 ГБ RAM (минимум)
- 1 ГБ свободного места на диске

## Установка

### С помощью pip

1. Установите Python 3.8 или выше
2. Скачайте исходный код
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python main.py
   ```

### С помощью .exe файла

1. Скачайте готовый .exe файл
2. Запустите его без установки

## Использование

1. Запустите приложение
2. Программа автоматически обнаружит ваше оборудование
3. Создайте или выберите профиль
4. Начните игру — FPS Targeter будет работать в фоне
5. Используйте горячие клавиши для управления:
   - `Alt+F` — переключить отображение FPS
   - `Ctrl+Shift+R` — сбросить настройки
   - `Ctrl+Shift+F` — переключить FPS

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| Alt+F | Переключить отображение FPS |
| Ctrl+Shift+R | Сбросить настройки |
| Ctrl+Shift+F | Переключить FPS |

## Сборка в .exe

### Способ 1: Простая сборка (рекомендуется)

Для создания исполняемого файла запустите:

```bash
cd src
simple_build.bat
```

### Способ 2: Полная сборка

Для создания исполняемого файла с полным набором зависимостей запустите:

```bash
cd src
build.bat
```

### Способ 3: Ручная сборка

```bash
cd src
pip install pyinstaller
pyinstaller --onefile --windowed --clean main.py
```

Готовый .exe файл будет находиться в папке `dist/`.
