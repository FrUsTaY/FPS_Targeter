# FPS Targeter - Релиз

## Описание

FPS Targeter v2.3 - это мощный инструмент для мониторинга и оптимизации производительности игр. Приложение автоматически обнаруживает оборудование, отслеживает FPS в реальном времени и предлагает оптимальные настройки для максимальной производительности.

## Системные требования

- Windows 10/11 (64-bit)
- Python 3.8+ (для исходного кода)
- 4 ГБ RAM (минимум)
- 1 ГБ свободного места на диске

## Файлы проекта

### Основные файлы

- `main.py` - главный файл запуска приложения
- `requirements.txt` - список зависимостей Python

### Файлы конфигурации

- `fps_settings.json` - настройки приложения
- `game_presets_db.json` - пресеты для игр
- `game_requirements.json` - системные требования игр
- `hardware_benchmark.json` - база данных производительности

### Скрипты сборки

- `simple_build.bat` - простая сборка в .exe (рекомендуется)
- `build.bat` - полная сборка с очисткой
- `build.sh` - сборка для Linux/Mac (требуется Wine)

### Документация

- `README.md` - основная документация
- `CHANGELOG.md` - история изменений
- `LICENSE` - лицензия MIT

## Установка

### С помощью pip

1. Установите Python 3.8 или выше
2. Скачайте исходный код
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```bash
   python main.py
   ```

### С помощью .exe файла

1. Скачайте готовый .exe файл
2. Запустите его без установки

## Сборка в .exe

### Способ 1: Простая сборка (рекомендуется)

Для создания исполняемого файла запустите:

```bash
cd src
simple_build.bat
```

### Способ 2: Полная сборка

```bash
cd src
build.bat
```

### Способ 3: Ручная сборка

```bash
cd src
pip install pyinstaller
pyinstaller --onefile --windowed --clean main.py
```

Готовый .exe файл будет находиться в папке `dist/`.

## Использование

1. Запустите приложение
2. Программа автоматически обнаружит ваше оборудование
3. Создайте или выберите профиль
4. Начните игру — FPS Targeter будет работать в фоне
5. Используйте горячие клавиши для управления:
   - `Alt+F` — переключить отображение FPS
   - `Ctrl+Shift+R` — сбросить настройки
   - `Ctrl+Shift+F` — переключить FPS

## Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| Alt+F | Переключить отображение FPS |
| Ctrl+Shift+R | Сбросить настройки |
| Ctrl+Shift+F | Переключить FPS |
