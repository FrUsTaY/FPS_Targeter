# FPS Targeter v2.3 - Руководство по запуску

## 🚀 Быстрый старт

### С помощью готового .exe файла (рекомендуется)

1. Перейдите в папку `src/dist/`
2. Убедитесь, что в папке находятся:
   - `FPS_Targeter.exe` (86 MB)
   - `game_requirements.json` (205 байт)
   - `hardware_benchmark.json` (4086 байт)
   - `overlay_settings.json` (150 байт)
3. Запустите `FPS_Targeter.exe` - приложение готово к работе!

### С помощью исходного кода

1. Убедитесь, что у вас установлен Python 3.8+
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите приложение:
   ```bash
   cd src
   python main.py
   ```

## 📝 Что происходит при первом запуске

При первом запуске .exe файла в папке `src/dist/` автоматически создадутся:
- `fps_data.db` - база данных SQLite (45 KB)
- `fps_settings.json` - настройки приложения (600 байт)
- `fps_targeter.log` - лог-файл (11 KB)
- `game_presets_db.json` - пресеты для игр (178 байт)

Это нормальное поведение, все файлы создаются автоматически.

## 🔧 Технические детали

- Размер .exe файла: ~86 MB
- Требования к системе: Windows 10/11 (64-bit), 4 ГБ RAM
- Приложение не требует установки Python
- Все данные хранятся локально в папке `src/dist/`

## 📧 Поддержка

Если у вас возникли проблемы, проверьте:
1. Лог-файл `fps_targeter.log` в папке `src/dist/`
2. Убедитесь, что все обязательные файлы присутствуют
3. Проверьте, что у вас есть права на запись в папку `src/dist/`
